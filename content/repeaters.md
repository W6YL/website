# Repeaters

### W6YL SJSU Repeater (UHF)
Open to public, great coverage troughout the campus and surrounding areas. \
Located on top of Engineering building.
|||
| :----: | :----: |
| Frequency: | 443.900 |
| Tone: | 100.00 Hz |
| Offset: | +5.000 MHz |

Our repeater has PL reverse burst enabled, so you can set a recieve tone of 100.0 Hz and have no squelch burst at the end :D

### MDC1200
Some members use MDC1200 data on this repeater for paging, so you may hear periodic data bursts. \
**Please do not enable PTT ID** as this is percieved as annoying to radios with no MDC mute.
#### Group ID
MDC Group ID (sometimes called "Variable ID"): **E621** or **621** (for Variable ID). \
All radios *should* be programmed with this group ID to enable paging of all users. 
#### MDC Emergency
MDC Emergency is supported on this system however it cannot be relied on, as other users will only get an emergency notification if their radio is on, and as of this time there is no dispatch console attached. \
Please do not send an MDC emergency alert unless there is an actual emergency, as it makes our radios go crazy
